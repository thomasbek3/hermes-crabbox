# Example coding assignment

Replace the placeholders before submitting. Supply the source snapshot through
MCP inputs or the HTTP caller's `--github` / `--repo-dir` option.

## Outcome

In OWNER/REPO at COMMIT_SHA, fix ISSUE_OR_BEHAVIOR. A user should be able to
DESCRIBE_THE_EXPECTED_RESULT.

## Scope

Read the repository's agent instructions, contribution guide, and PR template.
Keep changes focused on this assignment. Do not merge, deploy, modify production,
or contact external users. Do not change unrelated files or discard existing work.

## Acceptance

- Reproduce the issue or establish the current behavior.
- Implement the requested result and run the relevant repo checks.
- For visible UI changes, inspect the result and capture useful screenshots or
  a short recording using the installed evidence skills.
- Report actual check results and any remaining limits.

## Handoff

Save the changed source, a concise change summary, commands/results, and evidence
in the workspace for export. Read the repo's PR submission rules before drafting
its description. Return material for the parent agent to review and publish;
this assignment does not authorize merge or deployment.
