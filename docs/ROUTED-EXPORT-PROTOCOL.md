# Stopped-workspace export protocol

`routed_export_protocol` supplies a standalone collector program and independent controller decoder. It does not start Docker, establish quiescence, mount storage, create host files, register artifacts or authorize a verification outcome. The runtime must bind the exact stopped attempt workspace read-only at `/workspace`, execute the pinned program as tool UID1000 with no network/credentials/host socket, and confirm collector cleanup before using the returned bytes.

## API

- `ExportLimits(max_bytes=32*1024**2, max_entries=2000, max_depth=32, max_seconds=30)` is frozen. Absolute caps are 128 MiB, 10,000 entries, depth64 and120 seconds; zero data bytes is valid for empty files/directories. Booleans and nonfinite limits are rejected.
- `normalize_selectors(selected_paths)` accepts a nonempty explicit tuple and returns a sorted tuple. Paths are relative, positive, UTF-8 and at most1024 bytes, with no traversal, empty components, backslashes, controls, surrogates, duplicate/overlapping roots or whole-workspace `.`. The canonical selector list is capped at32 KiB so the generated `python -c` argument stays bounded. Legitimate `.github` and `.gitignore` paths remain supported. Private-state exclusions match the revision primitive and have a parity regression test.
- `collector_program(selected_paths, limits=ExportLimits(), *, workspace='/workspace')` returns standalone Python source for `python -I -S -c`. Only local tests use the workspace override; runtime callers must leave `/workspace` unchanged. No application imports or non-stdlib packages are needed inside the collector.
- `max_stream_bytes(limits)` returns `4*ceil(max_bytes/3) + 8192*max_entries + 65536`. The runtime must bound stdout capture to this cap, separately bound stderr, require successful process exit, and enforce its own process/cgroup deadline. A valid stream alone cannot prove successful physical cleanup.
- `decode_export(data: bytes, *, selected_paths, limits=ExportLimits(), forbidden_values=())` validates the complete stream and returns frozen `ExportTree(files, directories, sha256)`. Files are an immutable tuple of `ExportFile(path, data: bytes, executable: bool)`; directories are a sorted tuple of relative strings. The tree digest is the exact transcript digest below, not a revision/attempt identity or verification receipt. `forbidden_values` is a tuple of at most128 nonempty byte strings, each at most64 KiB; any match in decoded contents or UTF-8 paths rejects the entire export.

## Version1 wire format

Every record is one canonical ASCII JSON object followed by one newline. Canonical encoding is Python `json.dumps(value, sort_keys=True, separators=(',', ':'), ensure_ascii=True, allow_nan=False)`. The decoder requires those exact bytes, rejects duplicate keys, nonfinite numbers, unknown fields and coercions, and accepts no trailing data.

1. Header: `{"type":"header","version":1,"selected_paths":[...]}`. The selectors must exactly match the controller's normalized selectors.
2. Zero or more directory records: `{"type":"directory","path":"src"}`. Directories are strictly lexicographically ordered and precede all files. Necessary selector ancestors are included once. All non-top-level paths require their parent directory to have appeared.
3. Zero or more file records: `{"type":"file","path":"src/main.py","size":7,"data_b64":"...","sha256":"...","executable":false}`. Files are strictly lexicographically ordered. Canonical base64 must decode to exactly `size` bytes and match the declared SHA256. The executable boolean records whether any original execute bit was set; it does not instruct the controller to execute the file or restore arbitrary permissions/ownership.
4. Exactly one terminal record: `{"type":"terminal","entries":N,"bytes":B,"sha256":"..."}`. `entries` counts directory plus file records; `bytes` counts decoded file contents. SHA256 covers every preceding exact record including its newline, excluding the terminal record. Every requested selector must appear as a file or directory. Missing/partial/mismatched terminal records fail the whole stream.

One file uses one bounded JSON record. The total wire cap includes base64 rounding, worst-case escaped path lengths and the selector/header allowance. This is a complete bounded byte transport, not a constant-memory streaming decoder: both sides can hold multiple copies of file/protocol bytes during JSON/base64 encoding. Runtime memory policy must account for that overhead, especially when raising the default32 MiB content cap.

## Filesystem and failure boundary

The collector opens the fixed workspace and each path component with directory descriptors and no-follow semantics. It visits only requested roots and required ancestors. Symlinks, hardlinked regular files, devices, sockets and FIFOs are refused. It checks entry/depth/aggregate-byte limits while scanning, checks time cooperatively, compares file and directory device/inode/mode/size/mtime/ctime/link-count signatures around reads, and verifies path identities after traversal. It bounds directory-name inventories before sorting. Directories shared by file selectors count once; unselected siblings are not traversed.

The collector emits no records until its scan succeeds. Later write/deadline errors may leave a prefix without a terminal; that prefix is not usable. Exceptions produce only fixed `workspace_export_failed` stderr and nonzero exit. It never evaluates workspace content. The decoder independently checks schema, selection containment, parent coverage, private paths, duplicates, order, content/hash/base64 correctness, counts, complete terminal and known-secret bytes. A malicious or truncated producer cannot bypass these checks by supplying a self-consistent digest for an invalid tree.

Stat checks detect observed drift; they cannot replace the runtime's physical-stop proof or protect against an external privileged writer coordinating changes between observations. Cooperative clocks cannot interrupt a blocked filesystem read/write or expensive native JSON operation. The outer process/cgroup timeout remains required. No native/auth state, original owner/group metadata, arbitrary file modes or success claims are carried by this protocol.

## Local evidence

Focused tests run the generated collector in real local `python -I -S` subprocesses against0600 files, executable files, Unicode/quote-containing names, selected subtrees, empty files/directories and malicious links/FIFOs/private paths. Instrumented subprocess regressions mutate a file during read and replace a traversed directory to prove drift rejection; those two tests explicitly modify only the test program. Decoder tests independently forge valid-digest streams with invalid schema, traversal, order, duplicate paths, missing parents, malformed/noncanonical base64, altered hashes/counts, truncated terminals, selection mismatch and secrets. This is local protocol evidence, not Linux Docker UID/mount, stopped-writer, collector cleanup or workflow qualification.
